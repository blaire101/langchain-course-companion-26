# Accessing the Official Course Materials

The official course platform states that lesson notebooks can be downloaded from the notebook menu:

1. Open the relevant lesson notebook.
2. Select **File**.
3. Select **Download as**.
4. Choose **Notebook (.ipynb)**.

Helper files can be viewed through **File → Open** in the course workspace.

Keep the official course notebooks for personal study according to the platform's terms. This companion package contains original materials and does not redistribute those notebooks.
