Agents and Tools — Audio Practice

Overview

I created a LangChain agent with two tools. The first retrieves subscription-plan facts, and the second calculates total cost.

Execution flow

The agent first calls the plan lookup tool, then passes the retrieved monthly price into the total cost tool, and finally generates a customer-facing answer.

Chain versus agent

A chain follows a predefined sequence, while an agent dynamically chooses tools and determines the next action.

Tool execution

The language model does not execute Python functions itself. It selects a tool and generates structured arguments, while the application runtime executes the function.

Why use tools

Tools provide deterministic, testable, and reusable capabilities. They reduce hallucination and separate reasoning from execution.
